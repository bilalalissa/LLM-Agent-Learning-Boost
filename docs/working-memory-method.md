# Working-Memory Method

Stage 2 creates the foundation for learning outputs that reduce overload.

## Product Rules

1. Chunk first, detail second.
2. One card equals one recall target.
3. Limit immediate choices to three next actions.
4. Use progressive disclosure: `Gist`, `Core`, `Details`, `Expert`, and `Practice`.
5. Pair media with nearby text and learning bits.
6. Prefer active recall over passive summaries.
7. Stage large sources when cards or concepts exceed limits.
8. Preserve evidence links back to source page, file, page number, timecode, region, section, or URL.

## Default Limits

- `maxVisibleActions`: 3
- `maxCardsPerSourceBeforeStaging`: 30
- `maxNewConceptsPerSession`: 7
- `preferredSessionMinutes`: 25
- `microSessionMinutes`: 5
- `dailyNewLimit`: 20
- `dailyReviewLimit`: 120

## Storage

Learning bits, cards, review logs, behavior logs, fallbacks, plans, goals, and RemNote export placeholders live under `.llm-wiki/learning/`.

Readable Obsidian pages live under `wiki/learning/`, including dashboard, today, due reviews, memory map, goals, plan, behavior insights, fallbacks, resources, and language pages.
